# YouTube Downloader 操作ガイド

## 起動

ビルド済みの `YoutubeDownloader.app` を開きます。更新スクリプトで配置した場合は `/Applications/YoutubeDownloader.app` が利用先です。ルートやdistに残る旧版と取り違えないでください。

開発時はプロジェクトのトップで `.venv/bin/python main.py` を実行します。環境の準備は [README](../../README.md) を参照してください。

## ダウンロードする

1. 動画URLを入力して「追加」またはReturnでキューに追加します。入力欄が空のときに「追加」を押すと、クリップボードのURLを取り込みます。複数行の場合は一括追加ダイアログで確認します。Returnは入力欄だけを使います。プレイリストも追加できます。
2. 複数URLは「URLを一括追加」に1行ずつ入力します。無効な行はスキップ件数が表示されます。
3. チャンネルURLは「チャンネルから取得」を使います。取得結果の画面でURLを確認して追加します。
4. 動画か音声を選びます。動画は最高画質・2160p・1440p・1080p・720p、音声はMP3またはWAVです。MP3のビットレートは320・256・192・128 kbpsです。
5. 保存先を確認します。初期値は `~/Downloads` で、「変更」から選び直せます。
6. 「ダウンロード開始」またはCommand＋Returnで開始します。既定の同時ダウンロード数は2です。

キューが空でも、入力欄の有効な動画URLから「ダウンロード開始」で直接開始できます。プレイリストも直接開始でき、展開後にダウンロードします。チャンネルは取得結果の確認後に開始します。情報取得中の項目も、取得完了後に開始されます。

画面左側で形式と保存先を設定し、右側に一覧を表示します。一覧のみスクロールし、全体進捗と開始・停止ボタンは常に表示します。外観はmacOSのライト／ダーク設定に追従します。一覧右上のメニューから再試行やクリアを行えます。

サムネイル、再生時間、投稿者、容量は情報取得後に表示します。画像が取得できないときは動画アイコン、容量が不明なときは「—」を表示します。表示容量は取得情報とともに更新され、完了時には保存ファイルの実サイズになります。全体の容量欄はネットワークで受信した量で、変換後の保存容量とは異なる場合があります。変換・結合中は100%にせず、すべて成功した時点で完了表示になります。

「すべて停止」で中断を要求します。通信や変換が終わるまでは「停止処理中」と表示します。残っている待機項目は自動再開しません。再試行時は進捗とエラー表示がリセットされます。

同名のファイルは上書きせず、「タイトル (2).mp4」などの連番で両方残します。実行中・停止処理中は形式と保存先を変更できません。完了ダイアログから、その処理が使用した保存先を開けます。

ウィンドウを閉じる操作は全バックグラウンド処理の終了を待ちます。「処理の終了を待っています」と表示されたら、通信・変換・更新の終了までお待ちください。通常の中断・失敗では専用の途中ファイルを片付けます。

プレイリスト展開中もバッチの完了を待ちます。取得失敗はURLと理由を表示し、結果の失敗件数に含めます。再試行する場合は対象URLを再追加してください。「すべてクリア」後は古い一覧取得結果を取り込みません。

URLは1行に1つ入力してください。スキーム省略はHTTPSで補完します。URL内の%エンコードやカンマは勝手に書き換えません。

## 失敗したとき

キューに表示される理由と `~/Library/Logs/YoutubeDownloader/app.log` を確認します。削除済み・非公開・地域制限など、再試行だけでは解決しない場合があります。変換には外部のFFmpegが必要です。

ソース版は起動時にpip経由でyt-dlpの更新を確認します。更新は次回起動時から反映されます。**.app版は自己更新できません。** エンジンが古い場合はプロジェクトで `./scripts/update-and-install.sh` を実行し、更新・再ビルド・利用先への配置を行ってください。403にはエンジン以外の原因もあります。
