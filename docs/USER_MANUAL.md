# YouTube Downloader ユーザーマニュアル

YouTube Downloader をご利用いただきありがとうございます。本マニュアルでは、アプリケーションの基本的な使い方から、効率的にダウンロードを行うための便利な機能までを分かりやすく解説します。

---

## 1. アプリケーションの起動方法

リポジトリ内にある **`StartYoutubeDownloader.command`** をダブルクリックしてください。
- 初回起動時は、自動的に必要な環境の構築（仮想環境の作成やライブラリの導入）が行われます。
- 構築完了後、自動的にメインウィンドウが表示されます。

---

## 2. 画面構成と各機能

メイン画面は以下の5つのセクションで構成されています。

### ① URL入力セクション
ダウンロードしたい動画の URL を指定する場所です。
- **入力欄**: YouTube の動画、プレイリスト、またはチャンネルの URL を貼り付けます。
- **追加ボタン / ⏎ (Return) キー**: 入力した URL を下の「ダウンロード待ちリスト」に追加します。
- **URLを一括追加**: 複数の URL をまとめて追加したいときに使用します。
- **チャンネルから取得**: チャンネル URL を入力した状態で押すと、そのチャンネルに含まれるすべての動画 URL を自動的にスキャンしてリストアップします。

### ② ダウンロード待ちリスト (キュー)
追加された動画が一覧表示されます。
- **タイトル/時間**: 動画の情報が表示されます（取得中になる場合もあります）。
- **ステータス**: 「待機中」「ダウンロード中」「完了」「失敗」などの状態がわかります。
- **操作ボタン**: 項目ごとの「削除」や、失敗した項目の「再試行」が可能です。

### ③ 形式・設定セクション
保存するファイルの形式を指定します。
- **保存形式**: 「動画」か「音声」を選択します。
- **詳細設定**: 
    - 動画の場合：解像度（4K, 1080p, 720p など）を選択可能。
    - 音声の場合：フォーマット（MP3, WAV, FLAC, M4A）とビットレートを選択可能。

### ④ 保存先セクション
ダウンロードしたファイルの保存場所を指定します。
- デフォルトではあなたの「ダウンロード」フォルダに保存されます。
- 「変更」ボタンを押すと、任意のフォルダを選択できます。

### ⑤ 進捗・操作セクション
- **プログレスバー**: 全体のダウンロード進捗をパーセント表示します。
- **ダウンロード開始ボタン**: リストにある動画のダウンロードを一斉に開始します。
- **全て停止ボタン**: 実行中のダウンロードをすべて安全に中断します。

## 3. 便利な使い方

### チャンネル内の動画をすべて落とす
1. チャンネルのトップページ（例: `https://www.youtube.com/@AI仙人ch`）の URL をコピーします。
2. アプリの入力欄に貼り付けます。
3. **「チャンネルから取得」**ボタンを押します。
4. 動画の一覧が表示されるので、必要に応じて調整し「追加」を押すと、すべての動画がキューに入ります。

### ショートカットキーの活用
- **`⌘ (Command) + ⏎ (Return)`**: 「ダウンロード開始」ボタンを押す代わりに、キーボード操作だけでダウンロードを開始できます。
- **URLの自動修正**: ブラウザからコピーした際に URL が記号だらけ（`%E3...`など）になっても、貼り付けると自動的に元の日本語の名前に戻るので、内容を確認しやすくなっています。

## 4. 困ったときは

### ダウンロードが「失敗」になったら
- ネットワークの一時的な瞬断や、YouTube 側の制限が原因の場合があります。
- キューにある**「再試行」**ボタン、または下の**「失敗を再試行」**ボタンを押すと、失敗した項目だけをもう一度ダウンロードできます。

### ファイルがどこにあるかわからない
- ダウンロード完了時に表示されるメッセージの**「保存先を開く」**ボタンを押すと、保存したフォルダが Finder で開きます。

### アプリの動きがおかしい
- 一度アプリを閉じて再起動してみてください。起動時に YouTube エンジンの自動アップデートが行われ、問題が解決することがあります。
- それでも解決しない場合は、ログファイル（`~/Library/Logs/YoutubeDownloader/app.log`）を確認し、開発者に連絡してください。
