# YouTube動画ダウンロードソフト 要件定義ドキュメント

## プロジェクト概要
- **目的**: YouTubeのURLを入力すると動画がダウンロードされるMac向けソフト。
- **最重要要件**: シンプルで保守運用しやすい設計、快適な動作（速いレスポンス、少ないエラー）。
- **環境**: Mac (darwin 25.0.0)、Shell: /bin/zsh。
- **作成日**: 2025年11月9日
- **バージョン**: 1.0 (初期定義)

## Phase 1 要件まとめ
- **入力方法**: GUIでURLを貼り付け。
- **ダウンロード対象**: 動画（MP4）と音声（MP3）のオプション、解像度選択可能。
- **出力形式と保存場所**: MP4固定（拡張可能）、Downloadsフォルダ、ファイル名は動画タイトルベース。
- **複数動画対応**: 単一動画から開始、将来的にプレイリスト追加可能。

## Phase 2 要件まとめ
- **動作の流れ**: URL入力フィールド + ダウンロードボタン + プログレスバー + 進捗表示 + 完了通知（ポップアップ/ログ）。設計が複雑なら段階実装。
- **エラーハンドリング**: GUIにエラーメッセージ表示 + ログ出力 + 再試行ボタン（提案: 快適動作のため、ユーザー向けフィードバックを優先）。
- **依存ライブラリと技術スタック**: Python + Tkinter (GUI) + yt-dlp (ダウンロード)。インストールはpipで自動（提案: シンプルでMac互換性高く、初心者向け）。

## Phase 4 要件まとめ（提案ベース）
- **コード構造設計**: main.py (メイン実行)、gui.py (UI部分)、downloader.py (yt-dlpラッパー)、requirements.txt (依存リスト)、utils/logging_config.py (ログ設定)。モジュール化で保守しやすく、自動更新・ログ共通処理を分離。
- **テスト計画**: 単体テスト（URL検証、自動更新結果のログ確認）、統合テスト（ダウンロード成功/失敗、上書き確認フロー）、手動テスト（GUI操作）。基本テストで快適動作確認。
- **デプロイ/実行方法**: python main.py で起動、pip install -r requirements.txt で依存インストール。初回起動時にyt-dlp自動更新を行い、macOS向けシンプル実行を優先（アプリ化は後回し）。
- **自動更新とログ前提**: 起動時にyt-dlp自動更新を試行し、結果を`~/Library/Logs/YoutubeDownloader/app.log`へ記録。ログは1MB×5世代で自動ローテーションする。
