# テスト計画

## 手動テスト項目
- **起動確認**: `source .venv/bin/activate`（初回は `.venv` を作成）後に `make run`（または `StartYoutubeDownloader.command` をダブルクリック）を実行し、GUIが起動することを確認する。
- **URL入力検証**: URL未入力および不正なURLを入力し、「ダウンロード」ボタン押下時にエラーダイアログが表示されることを確認する。
- **保存先変更**: 「変更...」ボタンでフォルダを選択し、パスが更新されることを確認する。
- **フォーマット切替**: 「動画 (MP4)」「音声 (MP3)」を切り替え、選択状態が変わることを確認する。
- **解像度選択**: コンボボックスで 720p / 1080p / 1440p / 2160p / 4320p を切り替え、選択値が保持されることを確認する。
- **ショートカット**: URL入力後に ⌘+Enter でダウンロードが開始されることを確認する。
- **ダウンロード進捗**: 有効なYouTube URLを入力し、進捗バーとステータスメッセージ（残り時間表示）が更新・安定していることを確認する。
- **完了通知**: ダウンロード完了時にポップアップが表示され、保存ファイルのパスが案内されることを確認する。
- **ログ確認**: ダウンロード終了後、`~/Library/Logs/YoutubeDownloader/app.log` に進捗・完了ログが追記されていることを確認する。
- **エラーハンドリング**: ネットワーク切断や保存先を権限のない場所に変更するなどしてエラーを発生させ、エラーダイアログとログ出力が適切に表示されることを確認する。

## 将来的な自動テスト方針
- **URL検証の単体テスト**: URLバリデーションロジックをユニットテストでカバーする。
- **ダウンロード処理の統合テスト**: モック化した`yt_dlp.YoutubeDL`を用いて成功・失敗パターンを検証する。
- **GUIのスモークテスト**: `pytest-tkinter` などを利用し、ウィジェットの生成と主要イベントを自動確認する。
- **ログ設定のテスト**: RotatingFileHandlerの設定値やログ出力先をテストで検証する。
